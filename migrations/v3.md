Project-side changes from v2 to v3. The skill `migrate` applies them in this order. Steps marked `[ask]` need one answer from the user; when the user gives none, leave the template comment and one placeholder line.

Rules that `DEV/CLAUDE.md` gained in v3 (check escalation, security audit, sensitive paths, principles, review at feature completion) need no project change; they apply as soon as `DEV/` is on v3. The new skills and agents (`break-ui`, `migrate`, `Reviewer`, and `security-audit` when installed) are linked by `migrate` step 5.

## 2. `CLAUDE.md`: Sensitive paths

`[ask]` "Which files or directories are expensive to get wrong: money, stored data formats, auth, external interfaces, release config?" One path per line with the reason.

## 3. `DESIGN.md` and the `## Design` section

First decide: does the project have a UI? (A screen, a form, an HTML page, or a host-app panel counts. A CLI, a bot, or an MCP server alone does not.)

No UI:
- Delete the `## Design` section from `CLAUDE.md`. Do not create `DESIGN.md`. Done.

UI, and `DESIGN.md` does not exist:
- Copy `_template/DESIGN.md` to the project root. Set `name` in the frontmatter to the project name and `description` to the first sentence of `## Purpose`.
- Move the `## Design` content of `CLAUDE.md` into it:
  - "Visual direction" → `## Overview`
  - "Colors and fonts" → one line in `## Overview`
  - "Component library" → the `Component library` key under `## Harness`
  - "Project-specific UI rules" → `## Do's and Don'ts`
- Replace the body of `## Design` in `CLAUDE.md` with the one-line pointer from the template.

UI, and `DESIGN.md` exists (Impeccable wrote it):
- Do not rewrite it. Insert the `## Harness` section from the template right after the frontmatter.
- Move the `## Design` content as above into the sections that already exist. Create `## Do's and Don'ts` at the end if it is missing.
- Replace the body of `## Design` in `CLAUDE.md` with the pointer.

In both UI cases:
- `[ask]` "KRDS mode for this project: `default`, `strict`, or `off`?" Suggest `off` for a host-app extension or a single-screen tool, `default` otherwise. Write the answer into `## Harness`.
- Fill `UI stack` under `## Harness` from `## Stack and structure` in `CLAUDE.md`.
